# WorkPlanX Website

Next.js App Router, TypeScript, and Tailwind CSS project scaffold. The page and components are placeholders; no homepage design or copy has been implemented.

## Commands

```bash
npm install
npm run dev
npm run build
npm run start
npm run lint
npm run typecheck
```

Project copy belongs in `src/content/site.ts`. Review the layout and business context in `docs/` before changes. Follow approved brand materials in `docs/brand/`.
